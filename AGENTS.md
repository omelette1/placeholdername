# Working preferences

- Preserve existing work and unrelated changes.
- Do not create local backup copies of this project.
- After completing a task that changes this repository, commit the task's changes and push to the configured remote branch. This is the user's standing authorization; do not ask again for routine commits/pushes.
- A task-specific instruction not to commit or push takes precedence. Never force-push, overwrite remote work, commit credentials, or include unrelated changes. Report authentication, push, verification or merge failures accurately.
- Run checks appropriate to the changes before committing. Do not create empty commits for tasks without repository changes.
