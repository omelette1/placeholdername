# Static showcase

Open this folder and run Changeproof: Review Project → Current files.
It deliberately contains unsafe JS/TS and configuration examples for evidence
navigation. Never run, build or deploy these files. No credentials are present.

Current-files review needs no Git or AI key. Install/configure the pinned Checkov
tool to include configuration findings. Code and infrastructure findings share
one sidebar/details panel. This is a configuration snapshot, not a deployed-state
or exploit assessment. Use an existing changed Git project separately for AI
review; the synthetic connection check does not submit this workspace.
